# Commands

Clavain ships **66** files under `commands/`: slash commands (`.md`) plus the
`degraded-modes.yaml` table.

The main sequence is `/route` (smart dispatch), `/sprint` (phase sequencer),
`/brainstorm`, `/strategy`, `/write-plan`, `/work`, `/quality-gates`,
`/verify` and `/land`. Support commands include `/clavain-doctor`,
`/clavain-status`, `/handoff`, `/triage` and `/pr-triage`.
