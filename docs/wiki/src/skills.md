# Skills

Clavain ships **28** skills, one directory each under `skills/`.

Workflow entry points: `using-clavain` (the router every substantive task
starts from), `writing-plans`, `executing-plans`, `landing-a-change`,
`ship` and `full-stop` (own a change to a merge-ready PR, then stop). Review and quality: `code-review-discipline`, `plan-reviewer`,
`refactor-safely`. Delegation: `codex-delegate`, `interserve-engine`,
`dispatching-parallel-agents`, `subagent-driven-development`.
Specific skills: `lane`, `remontoire`, `galiana`, `project-onboard`, `gardener`.

Every skill directory must hold a `SKILL.md`.
